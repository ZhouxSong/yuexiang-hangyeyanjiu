# 多源冲突裁决规则（Conflict Resolution）

多个子agent并行检索时，同一事实常出现不同数值或结论。主智能体必须按规则裁决，**不投票、不折中、不沉默**。

## 一、来源权威级（从高到低）

| 级别 | 来源类型 | 示例 |
|---|---|---|
| L1 | 官方监管/统计机构原文 | 国务院、卫健委、FDA、EMA、NMPA、统计局 |
| L2 | 交易所披露/公司官方公告 | 年报、中期业绩公告、招股书、10-K/10-Q |
| L3 | 权威行业数据库 | Insight、Rock Health、弗若斯特沙利文 |
| L4 | 主流财经媒体 | 证券时报、Reuters、新浪财经 |
| L5 | 聚合平台/自媒体 | 腾讯财经、雪球、公众号转述 |

**规则1（高级覆盖低级）**：高级别与低级别冲突时，采用高级别，记录低级别的差异值作为备注。

**规则2（同级冲突）**：同级别来源数值不一致时，优先采用"时间更新+口径更明确"的一方；仍无法判断则并列呈现。

## 二、数据类型专项规则

### 财务数据
- 以**公司披露原文（L2）**为唯一准绳；媒体转述（L4）仅用于定位线索。
- 预告值与正式值冲突 → 用正式值；仅有预告值 → 标注"预告区间，未经审计"。
- 币种冲突 → 统一折算并标注汇率，不混用。

### 市场规模
- 不同机构口径**天然不同**，不视为冲突——并列成表（口径|规模|CAGR|来源），正文选主口径并给理由。

### 时间/日期
- 政策发布日期以官方文件落款为准；媒体报道日期与落款不一致时，用落款。

## 三、裁决记录格式

每次裁决在《数据说明表》或汇总文档中留痕：

```
数据项：[指标名]
采用值：[X]（来源：[L级+机构+日期]）
舍弃值：[Y]（来源：[...]）
裁决理由：[高级覆盖 / 口径更明确 / 时间更新]
```

## 四、何时并列而非取舍

以下情形**不取舍，直接并列呈现**：
1. 市场规模多口径；
2. 盈利预告区间（下限-上限）；
3. 各方对同一事件的定性存在合理分歧（如"首次盈利"的口径差异：净利润vs经调整vs单季）。

并列时必须写明各口径的定义与来源，让读者可自行判断。

## 五、结论冲突（定性判断）

子agent对同一问题给出相反定性结论时：
1. 回到双方的原始证据重新核验；
2. 证据充分者胜，证据不足者弃；
3. 双方证据都成立但指向不同 → 说明分歧的条件边界（在什么前提下A成立、什么前提下B成立），不强行合一。

## 六、禁止事项

- ❌ 取平均值"折中"两个冲突数字；
- ❌ 少数服从多数投票定数据；
- ❌ 静默选一个而不记录理由；
- ❌ 用子agent的"估计"覆盖官方披露的"实测"。
