# 人工课题分配单模板（全要素型）

用于将检索/核实类课题分配给实习生或新员工执行。**按需生成**（用户明确要求时才出），通常在阶段1备料或阶段2数据连续化环节触发。每张单子可直接分发。

## 分配单结构（六要素，缺一不可）

```
════════════════════════════════════════
课题分配单 #NN
════════════════════════════════════════
一、课题背景（为什么做这个）
  - 所属项目/报告：[报告名称与章节位置]
  - 课题目的：[1-2句，说明该课题支撑报告的哪个论断]

二、检索清单（去哪找、搜什么）
  - 关键检索词：[给出中英文关键词组合，如"英矽智能 3696 2025年度业绩 收入"]
  - 优先信源：[按权威级列出：交易所公告 > 公司IR页 > 主流媒体]
  - 时间范围：[近N年 / 指定日期区间]
  - 排除项：[明确不要的信息类型，避免无效劳动]

三、口径要求（数据怎么记）
  - 币种/单位：[如"人民币亿元，保留两位小数"]
  - 报告期：[自然年/财年/半年，明确截止日]
  - 特殊口径：[经调整/一次性剥离/预告值须标注公告日期]
  - 数据缺失时：[标注"未披露"并说明替代口径，禁止估算填充]

四、交付模板（交回来长什么样）
  - 格式：[表格/文档，附字段清单]
  - 必填字段示例：
    | 数据项 | 数值 | 币种 | 报告期 | 来源名称 | 来源日期 | 置信度 |
  - 每条数据必须附来源链接或文件名

五、验收标准（怎样算合格）
  □ 每个数字有可点击的来源链接
  □ 币种与报告期标注完整
  □ 预告值/正式值已区分
  □ 缺失项已标注原因
  □ 与已确认数据无矛盾（如有矛盾须单独说明）

六、时间安排
  - 发放日期：[日期]
  - 截止时间：[日期]
  - 疑问对接：[遇到口径歧义先问，不要自行裁量]
════════════════════════════════════════
```

## 使用规则

1. **只在用户要求时生成**，不自动产出；
2. 分配单中的检索词与口径要求必须来自技能已确认的材料清单/数据说明表，确保与主流程口径一致；
3. 实习生回收的结果并入材料包或数据说明表时，主智能体仍需按权威级复核——**人工交付物不豁免核实义务**；
4. 一次可批量生成多张（如按公司分组），但每张必须自包含，不得写"参考上一张"。
