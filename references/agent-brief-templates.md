# 子任务 Brief 模板（Agent Brief Templates）

每个子任务的 prompt 都应自包含、目标明确、产出可验收。以下为四类常用角色的模板，方括号内为占位符。

## 1. 检索员（Retriever）

```
任务：仅做研究检索，不要写代码、不要修改任何文件。
背景：[项目背景1-2句，让子agent明白为什么要查]
检索目标：
  1. [具体问题1，含实体名、代码、年份等精确字段]
  2. [具体问题2]
  3. [具体问题3]
已知线索：[已确认的事实，避免重复检索或与之矛盾]
约束：
  - 优先来源：[官方披露 > 主流财经媒体 > 聚合平台]
  - 时间范围：近[1-2]年
  - 每个关键数字给出来源名称与日期
产出格式：按问题编号逐条回答，每条含【结论】【数据】【来源】【置信度 高/中/低】。
置信度低的条目明确标"待核"。
篇幅：[控制在N字以内 / 不限]。
```

## 2. 撰稿人（Writer）

```
任务：撰写[章节名]，这是[整份报告/文档]的一部分。
报告总主题：[一句话]
本章大纲：
  [逐节列出标题与每节要点]
已核实的素材（必须使用，不得改动数据）：
  [粘贴本章所需的全部数据点与来源]
写作要求：
  - 体例：[学术综述 / 券商研报 / 白皮书]
  - 语言：[中文，专业、客观、可核查]
  - 字数：约[N]字
  - 引用：正文用[1][2]上标式编号，对应文末参考文献
  - 禁止：编造数据、使用未在素材中出现的数字
产出：直接输出Markdown正文（含小节标题），不要输出执行过程说明。
```

## 3. 审校员（Critic）

```
任务：对以下文稿做一轮严格审查，只输出审查报告，不要改写原文。
文稿：
  [粘贴全文或指明文件路径]
审查维度（逐条给出发现）：
  1. 数据与来源一致性：每个数字能否对应来源？推算值是否标注？
  2. 编号连续性：章节、图表、参考文献编号有无跳号/重复？
  3. 引用对应：正文[n]是否都在参考文献表存在？有无孤儿引用？
  4. 口径一致：币种、报告期、统计口径前后是否一致？
  5. 逻辑与表述：有无自相矛盾、过度推断？
产出格式：
  - 总评分（0-100）与是否PASS（≥80为PASS）
  - 问题清单：每条含【位置】【问题】【严重度 高/中/低】【建议改法】
  - 若无问题，明确写"无发现问题"。
```

## 4. 图表制作员（Chart-maker）

```
任务：根据给定数据制作[1]张图表并保存为PNG，不要改动数据。
数据（已核实）：
  [结构化数据，含单位、时间、来源]
图表要求：
  - 类型：[柱状/折线/环形/气泡/时间轴]
  - 标题：[图题]
  - 配色：主色#1F4E79、强调#E87722；中文用Microsoft YaHei
  - 图注三要素：来源、口径、估计值标注
  - 尺寸：[宽N]，dpi=170
输出路径：[绝对路径]
产出：保存PNG后，回报实际保存路径与图片尺寸。不要改变任何数据点。
```

## 5. 对抗审查员（Adversarial Reviewer，逐章即时）

```
任务：对以下章节做一轮对抗审查，只输出《挑战清单》，不要改写原文、不要修改任何文件。
你与撰写过程完全独立，不要推测撰写意图。

待审章节全文：
  [粘贴该章全文]

该章对应生命周期阶段及风险侧重清单：
  阶段：[极早期/商业化早期/快速成长期/成熟期]
  风险清单：[从 lifecycle-templates.md 粘贴该阶段的风险侧重项]

本章使用的已核实素材清单：
  [数据项+来源，逐条列出]

挑战范围（严格限三类，不得扩散到其他方面）：
  1. 关键数据：来源是否权威？推算/插值是否合理？是否遗漏反方向数据？单位/币种/口径是否一致？
  2. 逻辑链：章内因果/递进是否成立？有无循环论证、以偏概全、把时间先后当因果？
  3. 遗漏与盲区：对照上述风险清单逐条核查，反面案例/失败案例/关键竞争者/监管风险是否缺位？

明确不挑战：核心结论与观点裁量、文风措辞、章节结构编排。

产出格式（每条按此结构）：
【挑战 N-1】类别：[关键数据/逻辑链/遗漏与盲区]
位置：第N章 N.x节 第M段
原文：「……」
质疑：[具体质疑]
依据：[支撑质疑的证据或逻辑]
建议处理：[采纳修正 / 补充论证 / 可驳回]
末尾汇总：共X条（各类别计数）。
```

## 6. 终版差异分析员（Diff Analyst，阶段6自进化闭环）

```
任务：对比同一份行业研究报告的"AI初版"与"用户终版"，逐节识别差异。
只记录事实差异，不做价值判断，不修改任何文件。

AI初版全文：
  [粘贴或指明文件路径]

用户终版全文：
  [粘贴或指明文件路径]

对比要求：
  1. 逐节（按章节标题对齐）对比，不遗漏任何一节；
  2. 差异分七类：删减 / 增补 / 改写 / 结构调整 / 口径修正 / 观点修正 / 图表调整；
  3. 纯格式差异（标点、空格、换行）合并为一组概述，不逐条列；
  4. 对每条差异推断用户意图，标注置信度（高/中/低）。

产出格式（每条按此结构）：
【差异 D-n】
位置：第X章 X.x节
类型：[七类之一]
初版内容摘要：「……」
终版内容摘要：「……」
意图推断：[……]（置信度：高/中/低）

末尾附：差异统计（各类型计数）+ 高频模式归纳（跨章节重复出现的同类修改）。
```

## 通用注意事项

- 所有模板的占位符必须替换为具体内容后再派发，禁止留空。
- "只研究不写码"或"需要写码"必须显式声明，避免子agent行为越界。
- 数据类子任务一律附上"不得改动数据"约束，防止二次加工引入误差。
